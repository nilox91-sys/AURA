# Contribuire

Usa un branch dedicato, mantieni il codice compatibile con Python 3.10+ e conserva i contratti dei provider. Le nuove connessioni devono usare API ufficiali, proteggere le credenziali e avere test con risposte simulate. Non aggiungere fallback a consumo senza scelta esplicita dell’utente.

Prima di una proposta esegui i controlli elencati nel README. Specifica cosa cambia, perché e come l’hai verificato. Per modifiche alla voce verifica anche interruzione, ripresa e gestione degli errori. Non includere ambienti, modelli, conversazioni o segreti.
